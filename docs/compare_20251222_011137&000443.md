# Experiment Note: Query Expansion + Diversification

## 실험 목표
짧고 추상적인 쿼리(예: "야식", "시원한 음료", "차가운 디저트")에서
- 표면 단어 매칭(밤=chestnut, 냉이=cold 오인)으로 튀는 결과를 줄이고,
- Top-K 결과의 "도배(중복)"를 완화해
추천 체감 품질을 개선한다.

## 실험 환경
- 데이터: food_data.csv (음식명 + 카테고리 + 영양소 일부)
- 모델:
  - Snowflake/snowflake-arctic-embed-l-v2.0
  - jinaai/jina-embeddings-v3
- 평가 방식: EVAL_QUERIES 정성 비교 (라벨 없음)

## 변경 사항
### 1) Query Expansion (규칙 기반)
- 짧은 키워드를 의미가 풍부한 문장으로 확장해 검색 의도를 강화
- 예: "시원한" → "시원한 차가운 아이스 iced cold"

> 주의: 현재 구현은 "완전 일치(match)" 기반이므로,
> "시원한 음료"처럼 복합 입력은 확장이 적용되지 않을 수 있다.

### 2) Diversification 후처리
- 검색 결과 Top-K에서 동일 토큰/동일 카테고리 반복을 제한하여
결과가 한 종류로 몰리는 현상을 줄인다.

## 관찰 결과 (개선 전 → 개선 후)
- 개선 전: Top-K 내 중복(국수/콩나물/빵류 등)이 다수 발생
- 개선 후: 중복이 눈에 띄게 줄어 “도배”는 완화됨
- 다만 일부 쿼리에서 Top-K가 충분히 채워지지 않거나,
  의미적으로 틀린 카테고리(예: 시원한 음료인데 HOT 차)가 남아있음

## 다음 개선 포인트
1) Query Expansion을 "부분 포함/토큰 기반"으로 확장 적용
   - 예: "시원한 음료", "야식인데 짜지 않은 거"에도 확장 적용되도록
2) Diversification이 Top-K를 비우지 않도록 fallback(원본 후보로 채우기) 추가
3) HOT/ICED, 디저트/음료 같은 속성을 canonical text에 명시(태그화)
   - temperature: cold/hot 등의 힌트를 텍스트에 주입
4) 쿼리 타입별 가드레일
   - "음료" 쿼리는 음료 카테고리 우선, "디저트"는 디저트 우선 등
