# 2026-11-16 개선 실험과 배포 판단

상태: 최종 메뉴 검색 후보를 운영에 적용. 범용 정확도/채식·영양 충족 보장을 달성한 것은 아니다.

## 재현부터 확인

운영 모델/인덱스를 사용하는 별도 Python 프로세스에서 시행했다. CPU thread1, 모델 캐시 재사용, 서비스 API/집계에 쓰기 없음. 기존12건의 baseline 결과 food_code/순서가 앞선 기준선과12/12 일치했다. 운영 CSV/인덱스/메타 SHA256도 이전 manifest의 로컬 아티팩트와 모두 일치했다. 단, 최초 인덱스 생성 코드·모델 계보는 여전히 확정하지 못했다.

기준선 추천 함수는 tools/baseline.py에 동결했다. 이는 기존 Lab CLI가 아니라 실제 운영 함수에서 추출한 snapshot이다. 공통 모델/인덱스 로더와 query_expansion/diversify는 버전 고정 서비스 소스를 필요로 한다. 원본 main.py SHA256은 각 결과의 hashes에 있다. 최신 서비스 main의 함수로 baseline을 대체하지 않도록 비교 도구가 snapshot을 호출한다.

## 실험 순서

1. `prompt-only.json`: 검색 prefix만 `query: `로 변경. 기존 후처리 유지. 점심의 노른자·흰자 문제와 김치볶음밥 검색이 개선됐다. 부정 조건은 여전히 실패했다. 입력 형식 변경 채택.
2. `combined-v1.json`, `retrieval-v1.py`: 메뉴 자격/조건/이름 검색/다양화 조합. 온도 태그가 부정확해 야끼소바가 냉면 요청에 들어갔다. 국물 단독 항목도 남았다. **그대로 배포하지 않음**.
3. `combined-v2.json`, `retrieval-v2.py`:12개 탐색 사례 + 사전 작성한 추가6개 표현/예외 사례를 비교. 계란/달걀 동의어, 야끼소바의 '소바' 부분 일치, 커피/차 혼재를 발견.
4. `final-candidate.json`, `tools/retrieval.py`: 위 예외를 보정한18건 재평가 후 채택. 이때 추가6건도 보정에 사용했으므로 더 이상 독립 holdout이 아니다. **독립 미사용 평가셋의 일반화 검증은 미완료**.

## 관측 변화

| 사례 | 기준선 | 최종 |
|---|---|---|
| 점심 | 달걀·노른자·흰자3/6 | 비빔밥·샌드위치·월남쌈·샐러드 등6개; 해당 단품0개 |
| 따뜻한 국물 | 라면 국물 단독 포함 | 국수전골·추어탕·알탕·감자탕 등6개 |

| 김치볶음밥 | 해당 메뉴0/6 | 김치 볶음밥·볶음밥_김치2개 |

각 단일 실행 지연 중앙값: baseline0.2157초 / prefix0.17895초(combined-v2), 최종0.2018초(final-candidate). 요청 순서/캐시 조건이 완전히 통제된 반복 성능 실험이 아니므로 '빨라졌다'는 성과로 쓰지 않는다. 배포 후 브라우저1440/390/320px, 카드 이동, 설명5단계, reduced-motion 및 JS오류0 확인.

## 채택한 구현

- 모델에 명시된 query prompt 사용, 부정 표현이 있는 검색은 잘못된 확장 규칙을 우회.
- 기본 완성 메뉴 후보와 음료/간식/명시 카테고리를 분리. 부위·국물만·소스 제외. 계란찜/달걀찜은 보존.
- 전 음식 벡터를 검색한 뒤 조건/이름 점수/메뉴군 다양화 순으로 처리. 14584개 규모에서 순차 기능 평가. 대규모 확장 성능은 미검증.
- 정규화한 정확 음식명이 존재하면 그 이름에 맞는 후보만 보여준다. 매칭이 없을 때는 의미 검색. 음식별 원본 코드/영양값 연결 유지.
- 조건에 맞는 결과 수가 부족해도 강제로6개를 채우지 않는다.

## 남은 한계와 다음 판단

- 메뉴·온도·맵기·육류 제외는 이름/태그 휴리스틱이다. 반찬과 한 끼 경계, 양념·숨은 재료, 크림라떼 등은 완전하게 분류하지 못한다. 감자튀김 같은 사이드가 저녁 후보에 남을 수 있다.
- 고단백/저염은 수치 기준과 섭취량 정규화가 아직 없다. 해결했다고 표시하지 않는다. '고기 없는'은 비건/알레르기 안전성을 보장하지 않는다.
- 이름 첫 부분 기준 메뉴군 제한은 다양성을 늘리지만 유효한 여러 변형을 과하게 줄일 수 있다. 냉면·두부찌개 등이 짧은 결과가 되는 현상을 사용자 피드백으로 확인한다.
- 동의어는 계란↔달걀만 추가. 일반적인 한국어 형태소/동의어 검색을 완성한 것은 아니다.
- 여러 규칙을 조합한 효과와 각 규칙의 개별 기여를 구별해야 한다. prefix 외 규칙은 아직 완전한 ablation을 하지 않았다.

다음 단계는 독립 평가셋, 메뉴 분류 경계의 사람 검토, 부정/영양 조건과 메뉴군 다양화의 개별 비교다. 모델 교체나 전체 인덱스 재생성은 현재 보류한다.
